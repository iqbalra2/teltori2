# Teltori Hair Care Combo — ল্যান্ডিং পেজ

## GitHub-এ পাবলিশ (এইটুকুতেই সাইট ও WhatsApp অর্ডার চালু)
1. ZIP এক্সট্র্যাক্ট করে ভেতরের **সব ফাইল ও ফোল্ডার** repository-তে আপলোড করুন (`index.html` সবার উপরের লেভেলে থাকবে)।
2. Settings → Pages → Branch `main` / `(root)` → Save।
3. কয়েক মিনিট পর `https://আপনার-নাম.github.io/repo-নাম/` এ সাইট চালু হবে।

## অ্যাডমিন এডিট মোড — পাসওয়ার্ড: **Teltori@2026**
পাবলিশ করা সাইটে গিয়ে:
- ওয়েবসাইটের যেকোনো ফাঁকা জায়গায় **ডাবল-ক্লিক** করুন, অথবা
- মোবাইলে **নিচের বাঁ দিকের ⚙ বাটনে** চাপুন

পাসওয়ার্ড দিলে এডিট মোড চালু হবে — উপরে একটা বার আসবে, আর যেসব লেখায় হালকা সবুজ ড্যাশ বর্ডার দেখবেন সেগুলোতে সরাসরি ক্লিক করে লিখতে/বদলাতে পারবেন (শিরোনাম, বর্ণনা, ধাপ, FAQ-র প্রশ্নোত্তর ইত্যাদি) এবং উপরের বার থেকে অফার মূল্য বদলাতে পারবেন। শেষে **"সেভ করুন"** চাপুন।

⚠️ **Firebase কনফিগার না করা থাকলে** এই বদল শুধু আপনার ওই ব্রাউজারেই থাকে (অন্য কেউ দেখবে না)। সবার জন্য স্থায়ীভাবে বদলাতে হয় নিচের Firebase ধাপগুলো করুন, নয়তো এডিট মোডের **"GitHub-এর জন্য ফাইল"** বাটনে `site-content.json` ডাউনলোড করে repository-র রুটে আপলোড করে দিন (আমাকে বললে পরের বার আমি এটাকে index.html-এ বসিয়ে দিতে পারব)।

নতুন প্রোডাক্ট/সেকশন যোগ করা, ছবি বদলানো বা বড় ধরনের পরিবর্তনের জন্য এখানে এসে বলবেন — আমি ফাইল আপডেট করে নতুন ZIP দিয়ে দেব।

## অর্ডার দেখা
- **নিজের অর্ডার (ক্রেতা):** সাইটের "আমার অর্ডার" বাটনে ক্লিক করলে দেখা যায়। অন্য কারও অর্ডার দেখা যায় না।
- **সব অর্ডার (অ্যাডমিন):** `আপনার-সাইট/admin.html` বা এডিট মোডের "অর্ডার দেখুন" বাটনে।

## Firebase চালু করা (সব দেশ/ডিভাইসের অর্ডার এক জায়গায় জমা রাখতে ও এডিট মোড সবার জন্য সেভ করতে) — ফ্রি
GitHub Pages-এ সার্ভার নেই, তাই এটা ছাড়া প্রতিটি অর্ডার শুধু ক্রেতার WhatsApp-এ যায় এবং অ্যাডমিন প্যানেল শুধু "ডেমো মোডে" নিজ ব্রাউজারের অর্ডার দেখায়।
1. console.firebase.google.com → Add project।
2. Authentication → Sign-in method → **Anonymous** ও **Email/Password** দুটোই Enable করুন।
3. Authentication → Users → Add user → ইমেইল `admin@teltori.com` (বা অন্য কিছু — তাহলে `js/config.js`-এর `adminEmail`-এও বদলান), পাসওয়ার্ড `Teltori@2026` (বা নিজের পছন্দেরটা — চাইলে বদলে নিন) → তৈরি হলে **User UID** কপি করুন।
4. Firestore Database → Create database (Production mode; লোকেশন asia-south1/asia-southeast1)।
5. Firestore → Rules → `firestore.rules`-এর পুরো লেখা বসান, `এখানে_অ্যাডমিন_UID_বসান`-এর জায়গায় ধাপ ৩-এর UID বসান → Publish।
6. Project settings → Your apps → Web (`</>`) → অ্যাপ রেজিস্টার করলে `apiKey, authDomain, projectId, appId` পাবেন → `js/config.js`-এর `firebase:{...}`-এ বসান → GitHub-এ আবার আপলোড।
7. Authentication → Settings → Authorized domains-এ `আপনার-নাম.github.io` যোগ করুন।

Firebase চালু করার পর অ্যাডমিন লগইনে (`admin.html`-এ) ধাপ ৩-এর ইমেইল ও পাসওয়ার্ড ব্যবহার হবে — ওয়েবসাইটের এডিট মোডের পাসওয়ার্ডও তখন সেটাই হয়ে যাবে।

## Google Tag Manager (GTM)
`js/config.js`-এ `gtmId: ''` লাইনে আপনার কন্টেইনার আইডি বসান (যেমনঃ `'GTM-XXXXXXX'`)। বসালেই সাইটে GTM লোড হবে। অর্ডার কনফার্ম হলে `dataLayer`-এ একটি `purchase_order` ইভেন্ট পাঠানো হয় (অর্ডার নম্বর, টাকার অঙ্ক, পরিমাণ সহ) — GTM-এ এটাকে ট্রিগার হিসেবে ব্যবহার করে Google Ads/Facebook Pixel কনভার্সন ট্র্যাক করতে পারবেন।

## অন্যান্য সেটিং (`js/config.js`)
- `price`, `regularPrice` — অফার মূল্য ও নিয়মিত মূল্য (এডিট মোড থেকেও বদলানো যায়)।
- `messenger` — মেসেঞ্জার আইডি বসালে বাটন চালু হয় (ফাঁকা থাকলে লুকানো)।
- `shopPhone` — WhatsApp নম্বর।
